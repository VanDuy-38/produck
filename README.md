## Quy ước khi gửi tư liệu dựng một tập

```
tapXX/
  clips/   1.1.mp4, 1.2.mp4 … (tên = số shot trong storyboard)
  vo/      H1.wav … H7.wav, MAM_1.9.wav (thoại nhân vật)
  music/   vui.mp3, cang.mp3, cinematic.mp3
  sfx/     snap_pop.wav …
```
