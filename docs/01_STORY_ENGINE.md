# 01 — STORY ENGINE

> How every episode is built. Pick a **format** (§2–§4), fill its **episode card** (§5), then choose a **combo** from the variety kit (§6) using the **selection rules** (§7). Log the combo in `04_EPISODE_LOG.md` *before* storyboarding.

---

## 1. The shared spine (all formats)

Every episode, whatever the format, runs on the same six-part spine:

```
HOOK ─► RULES ─► ESCALATION LADDER ─► TURN ─► CLIMAX (uses a setup) ─► CALLBACK + DOUBLE QUESTION
```

| Part | Job | Non-negotiables |
|---|---|---|
| **Hook** | Make the viewer *be* Bo inside 15 s. | A relatable moment + one visual gag. Explain nothing yet. |
| **Rules** | Give the viewer a game to play along with. | Exactly 3 numbered rules (`RULE 1/2/3`). Rule 3 must matter in the climax. |
| **Escalation ladder** | Each step is worse than the last. | Each rung = **1 real fact + 1 consequence + 1 gag**. 3–5 rungs. |
| **Turn** | Change the emotional key. | Involves the crush / best friend. Letterbox ON. Mood light goes blue or red. |
| **Climax** | Win with brains, not luck. | The solution must use something planted earlier (a rule, a gag, an object, a fact). |
| **Callback + double question** | Close the loop and start a conversation. | One callback to the hook gag. End on 1 **moral** question + 1 **mystery** question (Grey Raincoat). |

**Escalation ladder order** (use this to sort your problems):

```
BODY  →  PLACE  →  PEOPLE  →  SELF
needs     the setting   trust breaks   the hard choice
(cold,    turns hostile (secrets,      (give up something
hunger)                 blame)          that is "you")
```

## 2. FORMAT A — WHAT IF ("What If You Could…?")

*Science-of-a-superpower.* The fun is that the power *sounds* amazing until physics shows up.

| # | Beat | % | @10:00 | Content | Short? |
|---|---|---|---|---|---|
| A1 | Cold open | 4% | 0:00–0:25 | Small everyday problem → Bo uses the power to fix it → visual gag | ✂️ #1 |
| A2 | Real science | 10% | 0:25–1:25 | 2–3 real facts with BIG numbers on screen + 1 philosophical question | ✂️ #2 |
| A3 | Origin + 3 rules | 10% | 1:25–2:25 | When "you" first discovered it (age 12, embarrassing moment) + RULE 1/2/3 | ✂️ #3 |
| A4 | Wish-fulfilment montage | 8% | 2:25–3:15 | 5–7 fast "dream come true" shots | |
| A5 | Problems 1→4 | 25% | 3:15–5:45 | Each: setup → science consequence → funny result → **a new house rule** | ✂️ #4, #5 |
| A6 | Turn | 15% | 5:45–7:15 | Crush/best friend gets involved or hurt. Letterbox ON | |
| A7 | Climax + cliffhanger | 28% | 7:15–10:00 | Opponent or disaster → solved with RULE 3 → Grey Raincoat → double question | |

**Title formula:** `What If You Could [power]?` (+ optional suffix: `…for 24 Hours?`, `…(Science Says NO)`).

## 3. FORMAT B — POV ("POV: You…")

*Countdown survival + relationship.* The fun is "what would I do?" plus "will they?".

### 3.1 Title formula

```
POV: You  [are trapped / survive / have N days to / wake up]
          + [with your crush / best friend / rival / alone]
          + [in an extreme place]
          + [for 24 HOURS / 7 DAYS / 30 DAYS / 1 YEAR]
```

Examples: *POV: You're Snowed In at School With Your Crush for 7 Days* · *POV: You Survive 30 Days in a Bunker With Your Best Friend* · *POV: You Have 24 Hours Before Your Crush Finds Out Your Secret*.

### 3.2 The Countdown Ladder (12:00 template)

| # | Beat | % | @12:00 | Content | Short? |
|---|---|---|---|---|---|
| B1 | Hook | 3% | 0:00–0:20 | `DAY 1` card. The whole situation in **one image**, crush in frame. First VO line names the clock and the person. | ✂️ #1 |
| B2 | How you got here | 7% | 0:20–1:10 | 3–5 fast shots. **Never more than 50 s of backstory.** | |
| B3 | Rules of the place | 6% | 1:10–1:50 | RULE 1/2/3 = the constraints (exits, supplies, threat). | ✂️ #2 |
| B4 | Days, part 1 (BODY) | 26% | 1:50–5:00 | One day per rung: water / warmth / food. Each = fact + relationship micro-beat + gag. | ✂️ #3 |
| B5 | Midpoint twist (PLACE) | 8% | 5:00–6:00 | New information changes the game (someone else is here, supplies vanish, a secret). | ✂️ #4 |
| B6 | Days, part 2 (PEOPLE) | 21% | 6:00–8:30 | Trust breaks. **Low point ~8:00**: fight or separation. Letterbox ON. | |
| B7 | Final day (SELF) | 21% | 8:30–11:00 | The escape needs every setup. Bo gives up something that is "him". Crush payoff moment. | ✂️ #5 |
| B8 | Epilogue | 8% | 11:00–12:00 | Back to normal + callback gag + Grey Raincoat clue + double question. | |

### 3.3 Day-counter rules
1. The counter is **always on screen** (top-left) during the days section.
2. **Never show an empty day.** Skip days freely (`DAY 3 → DAY 6`), but say in one line what changed.
3. A day card always lands on an image that shows the new problem.
4. The last day is the longest. The first day is the shortest.

### 3.4 Crush / relationship rules (PG)
| Stage | Typical beat |
|---|---|
| Awkward | Silence, Bo says something weird, the mood light flickers pink |
| Forced teamwork | They need each other to survive a rung |
| Small kindness | Sharing the last snack, a hoodie, a nightlight |
| Misunderstanding | Blame, from the midpoint twist |
| Sacrifice | Bo gives up something for them in the final day |
| Payoff | A small moment: a high-five, a shared laugh, a gift. **No kiss, no confession** in Season 1 |

## 4. FORMAT C — HYBRID ("POV + What If")

A **power** from Format A + the **clock and relationship** from Format B.
Use it for tentpoles and season finales (≈ 1 in 8 episodes).

- *POV: You Can Stop Time, But Your Crush Is Immune*
- *POV: You Can Read Minds, Except Your Crush's*
- *POV: You Shrink to Ant Size the Day Before Prom*

Structure: B1–B3 from POV (with the 3 rules being the power's rules), then the A5 problem ladder rendered as days/hours, then B6–B8.

## 6. Variety kit: avoid formula fatigue

### 6.1 Frames (F1–F8)
| Code | Frame | Best for |
|---|---|---|
| F1 | **Seven Beats** (Format A table) | What If openers & finales |
| F2 | **Countdown Ladder** (Format B table) | Default POV |
| F3 | **24 Hours**: a clock (`00:00 → 23:59`), each hour block = a discovery or accident | Secrets, time powers, "before X finds out" |
| F4 | **One Day · One Year · One Hundred Years**: consequences scale with time | Immortality, no sleep, no pain |
| F5 | **Versus**: power A vs power B (or you vs rival), fighting-game stat cards, 3 rounds | Comment wars ("Who wins?") |
| F6 | **Someone Else Narrates**: Rae / Juno / Mom / the cat tells the story about Bo (no "you") | Fan favourite spin-offs, reveals |
| F7 | **Start at the End**: freeze on the worst moment → "12 hours earlier…" | Disasters, chaos plots |
| F8 | **Mr. Pickett's Lab**: hypothesis → Bo as test subject → 5 self-contained experiments | Cheapest to make, 5 Shorts guaranteed |

### 6.2 Tones (T1–T4)
| Code | Tone | Music | Light | Shot length | Bo faces |
|---|---|---|---|---|---|
| T1 | Comedy | Ukulele, pizzicato | Bright | 2–4 s | shocked, deadpan, nervous |
| T2 | Tense / spooky | Low drone, long silences | Dark, one-colour | 5–8 s | scared, determined |
| T3 | Heartfelt | Piano, strings | Golden hour, warm | 4–6 s | sad, crush, crying |
| T4 | Mystery | Synth pulse | Cold blue-violet | 3–5 s | thinking, confused |

One main tone ≥ 60% of runtime, maximum two tones per episode.

### 6.3 Openings (O1–O6)
| Code | Opening | Example |
|---|---|---|
| O1 | Everyday disaster | Missed the bus, one shoe on |
| O2 | Question to camera | "Do you know how heavy you'd be at the size of an ant?" |
| O3 | Worst moment first | Bo hanging from a ceiling fan: "So. Here's what happened." |
| O4 | Shock number | "0.3 seconds. That's how long you'd last if…" |
| O5 | Sound on black | 5 s of audio only, then picture |
| O6 | Someone else's voice | Mom's voicemail: "Honey, why is the school on the news?" |

### 6.4 Settings
Use background codes from `03_PRODUCTION_2D.md §3` (BG01–BG08, + new per-episode sets).

### 6.5 Pattern breaks (P1–P10), at least 1 per episode
| Code | Break |
|---|---|
| P1 | No rules section: the rules reveal themselves through action |
| P2 | Grey Raincoat doesn't appear, only an indirect clue |
| P3 | Fully happy ending, no cliffhanger |
| P4 | Bo never says the catchphrase; someone else says it |
| P5 | ≥ 30 s with **no words at all**, just music and picture |
| P6 | Fourth-wall break: Bo argues with the narrator |
| P7 | Start with **wrong** science, then correct it mid-episode ("Wait. That's wrong.") |
| P8 | A vertical 9:16 "phone video" inside the story |
| P9 | One-episode guest character |
| P10 | 15–30 s in a different art style (paper cut-out, pixel, pencil sketch) for a flashback |

## 7. Selection rules

1. **Frame** differs from the previous episode. F1 or F2 ≤ 50% of a season each.
2. **Format**: no more than 2 POVs in a row. Season mix target ≈ **60% POV · 30% What If · 10% Hybrid**. Re-balance using the metrics.
3. **Tone** differs from the previous episode.
4. **Opening** not used in the previous 3 episodes.
5. **Main setting** differs from the previous episode.
6. **Pattern break**: ≥ 1 per episode, same code not within 4 episodes.
7. Each season includes ≥ 1 T3 (heartfelt) and ≥ 1 F5 (versus).
8. If the previous episode's **AVD < 35%**, change both frame and tone, and write the reason in the log.
9. If the user/producer specifies a combo, it wins. Just log it.
