# 02 — QA CHECKLIST (run before every upload)

## 1. Script
- [ ] First 15 s: relatable situation + visual gag, no explanation yet
- [ ] Title promise delivered in the first 20 s (POV: the person + the clock are both on screen)
- [ ] Exactly 3 numbered rules; Rule 3 pays off in the climax
- [ ] Every ladder rung = 1 fact + 1 consequence + 1 gag
- [ ] ≥ 3 facts, each verified with a source in §5
- [ ] Climax uses something planted earlier (no luck, no new power)
- [ ] ≥ 2 callbacks (hook gag, headphones' wrong song, forgotten item)
- [ ] Turn/low point involves the crush or best friend
- [ ] Ends with moral question + mystery question + one Grey Raincoat clue
- [ ] ~150 words/min; no sentence > 20 words; US spelling
- [ ] Catchphrase ≤ 2 times
- [ ] 5 Shorts cut points marked ✂️, each understandable with zero context

## 2. Visuals
- [ ] Bo on model (`art/characters/bo/bo_model_sheet.svg`): headphones on, red jacket, white shoes, no nose/fingers
- [ ] Mood light colour matches the emotion in every shot
- [ ] Characters stand on the background's stage line (see `03_PRODUCTION_2D.md §3`)
- [ ] On-screen text ≤ 4 words, held ≥ 1.2 s, inside title-safe area
- [ ] Day/hour counter top-left, consistent across the episode
- [ ] Letterbox 2.39:1 switched ON at the turn and OFF at the epilogue
- [ ] No static shot > 6 s without camera move or character action
- [ ] Grey Raincoat placed and visible on a paused frame

## 3. Audio
- [ ] Signature "tap-tap" SFX every time Bo commits to a plan
- [ ] Music drops out 0.5 s before each punchline
- [ ] −14 LUFS integrated, dialogue ≥ 10 dB over music
- [ ] All music/SFX licensed (YouTube Audio Library, Epidemic, Artlist…)

## 4. Legal, safety & platform
- [ ] No other channel's characters, names, catchphrases, exact titles or thumbnail layouts
- [ ] Nothing a child could imitate dangerously without a clear "don't" (fire, ice, electricity, heights, carbon monoxide)
- [ ] Survival tips are presented as story, not instructions; real dangers are stated correctly
- [ ] PG relationship content only
- [ ] "Made for Kids" setting decided deliberately (teen-targeted animation is usually **not** made for kids; check YouTube's current guidance before each season)
- [ ] If AI voice/visuals are used, enable YouTube's altered/synthetic content disclosure where it applies
